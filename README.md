## 📖 About

AI-SecChat is a modern cyber security assistant that combines **Artificial Intelligence** with a simulated **Trusted Execution Environment (TEE)** to protect user data. It provides multiple security tools in a single dashboard, intelligently routing sensitive data to local AI and safe data to cloud AI.

---

## ✨ Features

| Feature | Description |
|---------|-------------|
| 💬 AI Security Chatbot | Ask any cyber security question, get instant AI answers |
| 🎣 Phishing Detector | Paste suspicious emails, get detailed phishing analysis |
| 🔑 Password Advisor | Check password strength and get improvement tips |
| 🔗 URL Safety Checker | Detect malicious and suspicious URLs |
| 🔐 TEE Audit Log | Track every request's routing (Local vs Cloud) |
| 🔒 PII Detection | Auto-detect sensitive data (Email, Phone, Card, Aadhaar) |
| 🎭 Smart Anonymization | Sensitive data auto-replaced before cloud processing |
